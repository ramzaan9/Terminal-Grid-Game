# Terminal Grid Game

A Python terminal game built as foundation year CS coursework at university.

![Gameplay](terminal-grid-game.gif)

## Features
- 3 difficulty levels: Apprentice, Assassin, and Nightmare
- Guards with independent random movement AI
- Collision detection and a live scoring system
- Full input validation and clean game loop architecture
- Menu system, player naming, and win/lose states
- Built using only Python's standard library

## Context
Foundation year coursework project. The base requirement was a simple grid with basic movement. I extended it significantly by adding enemy AI, difficulty scaling, a scoring system, and a full menu system.

## Concepts demonstrated
- Game loop architecture and state management
- Randomised enemy AI with boundary-constrained movement
- Collision detection across multiple dynamic entities
- Input validation with exception handling
- Function design to eliminate repetition
- Difficulty scaling through parameterised enemy spawning
